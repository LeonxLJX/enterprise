PUT http://127.0.0.1:3000/api/settings/document-schema/fields

Required: section.key, section.label, and a non-empty fields array. Each field requires key, label, description, value_type, and default. Optional: prominence and choices. Fields marked secret, containsSecrets, or using value_type: "secret" are rejected.
